Start here (2 minutes)

  1. Open the Start Here guide and the Visual Catalog (45 pages) to pick your first design.
  2. Download the folder of that category below (Dresses, Shirts, Jeans…). Each design has 4 files: A4 tiled, US Letter tiled, A3, and an illustrated instruction booklet.
  3. Print only page 1 at 100% / Actual size and measure the 10 cm / 4 in test square. If it's right, print the rest and tape the tiles following the assembly map.
